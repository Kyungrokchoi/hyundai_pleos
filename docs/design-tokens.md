# MOATA 디자인 토큰 (승객 웹, v2)

구현 기준 파일: [`passenger-web/src/app/globals.css`](../passenger-web/src/app/globals.css) (`:root` 커스텀 프로퍼티).
대비 비율과 시각 규칙은 `passenger-web/tests/tokens.test.ts` 가 **CSS 파일을 직접 읽어** 매번 검증한다(아래 표의 수치는 현재 팔레트로 계산한 값).
차량 앱(Compose)도 같은 색 값을 쓰되, Compose 화면 검증은 별도 수동 검토다(웹 감지기는 Compose를 검증하지 못한다).

## v2 방향: 조용한 도구, 소리 지르는 UI가 아님

v1은 굵은 2px 검은 윤곽선과 단색 오프셋 그림자를 모든 요소에 썼고, 모든 구획이 같은 크기로 외쳐서 "시끄럽고 불편하다"는 평가를 받았다. v2 규칙:

1. **한 화면에 주요 행동은 하나.** 노란색(`--moa`)은 그 하나의 버튼에만 쓴다(마스코트 일러스트 제외). 나머지 버튼은 중립 회색 면, 보조 행동은 밑줄 텍스트 링크.
2. **답을 먼저, 근거는 접어서.** 핵심(금액·한 문장·한 줄 고지)만 펼쳐 두고 계산식·전체 몫·공유는 `<details>` 아코디언(기본 닫힘).
3. **테두리와 그림자를 줄인다.** 면 색 차이(`--paper-2`)와 1px 헤어라인(`--rule`)으로 구분. 그림자는 **고정 하단 액션 바 하나**뿐(`--elev`).
4. **전문 용어를 쓰지 않는다.** 값의 출처는 "차량에서 읽은 값 / 직접 입력한 값 / 연습용 가상 데이터", 상태는 "기다리는 중 / 확인했어요 / 이의가 있어요", 거리는 출발 이후 거리(주행계 값은 승객에게 보이지 않음).
5. **법적 문구는 그대로, 위치만 바꾼다.** 서버가 준 안내 원문은 한 줄 요약 + "자세히"(또는 페이지 끝 "안내 보기") 뒤에 **글자 그대로** 둔다.

v1에서 쓰던 `--moa-soft`, `--moa-deep`, `--warn-bg`(연노랑 계열)는 "노랑은 주요 행동만"이라는 규칙에 맞춰 **삭제**했다. 주의 알림은 중립 면 + 아이콘 + 굵은 제목으로 구분한다.
지시서의 기본 청록 `#12A594`(paper 위 2.9:1)와 코랄 `#E5484D`(3.7:1)는 글씨로 쓸 수 없어 각각 `--route`/`--route-line`, `--alert` 로 나눠 어둡게 했다(원색은 모아 일러스트 안에서만).
**색만으로 의미를 전달하지 않는다**: 모든 상태는 아이콘 또는 글자와 함께 표시한다.

## 타이포그래피

폰트: **Pretendard Variable** (npm `pretendard@1.3.9`, SIL OFL 1.1, dynamic-subset woff2 자체 호스팅, 외부 CDN 없음). 대체: `system-ui, Apple SD Gothic Neo, Noto Sans KR, Malgun Gothic`.
본문 17px / 행간 1.6, 한글은 `word-break: keep-all`, 숫자는 `tabular-nums`. 굵기는 400/600/700/800.

| 토큰 | 크기 | 용도 |
|---|---|---|
| `--t-xs` | 14px | **캡션 전용**(배지 글씨, 갱신 시각). 문단에는 쓰지 않음 |
| `--t-sm` | **16px** | 보조 설명·법적 문구·메타 줄 (v1의 15px에서 상향) |
| `--t-md` | 17px | 본문 |
| `--t-lg` | 20px | 소제목·주요 버튼·한 문장 요약 |
| `--t-xl` | 26px | 화면 제목 |
| `--t-2xl` | 34px (≥640px 40px) | 이동 상태 한 줄, 첫 화면 제목 |
| `--t-num` | 52px / 800 | 이동 거리 |
| `--t-hero` | **64px** / 800 | 정산 화면의 "내가 낼 금액" |

장식용 소문자 라벨(kicker)은 쓰지 않는다. 라벨은 `.label`(16px 600, 자간 없음) 하나뿐이다.

## 간격 · 모서리 · 그림자

4pt 배수(`--s-1 … --s-8` = 4·8·12·16·24·32·48·64px). 화면 안 큰 덩어리 사이는 `--s-6`(32px), 덩어리 안은 `--s-4`(16px).
모서리: `--r-sm 12px`(입력·소형) · `--r-md 16px`(버튼·알림·대화상자) · `--r-pill`(배지·진행바). 본문 열은 최대 32rem 중앙 정렬.
**그림자는 `--elev` 하나**(하단 액션 바 위쪽으로만 번지는 옅은 그림자). 그라디언트·유리 효과(`backdrop-filter`)·카드 중첩 없음.

## 터치 영역

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--target` | **48px** | 모든 버튼·링크·체크박스 행·아코디언 제목의 최소 높이(v1 44px에서 상향) |
| `--target-lg` | **56px** | 주요 행동 버튼, 입력창, 아코디언 행 |

## 컴포넌트 규칙

- **고정 하단 액션 바** `.action-bar`: `position: sticky; bottom: 0`, `env(safe-area-inset-bottom)` 반영, 높이 ≥ 56px 버튼 + 위아래 12px. 화면에 **주요 행동 하나**(+ 필요하면 조용한 보조 하나)만 둔다. 내용이 짧아도 `min-height: 100dvh` 열 맨 아래에 놓인다.
  - 정산: `승인할게요`(주요) + `이의 있어요`(보조). 결정한 뒤에는 상태 줄("승인했어요 · 다른 분을 기다려요")과 텍스트 링크로 바뀐다.
  - 이동: `탑승했어요` 또는 `내렸어요` 중 해당하는 하나, 도착 후에는 `정산 보기`. **내린 직후에는 주요 버튼을 두지 않고**, 잘못 눌렀을 때를 위한 조용한 `다시 탔어요` 링크만 둔다.
  - 참여: `참여 요청 보내기`(두 동의에 체크하기 전에는 비활성 + 이유를 한 줄로 안내).
- **아코디언** `.acc`: 네이티브 `<details>`(기본 닫힘), 제목 행 56px, 오른쪽 화살표만 회전. 키보드·스크린리더 지원은 플랫폼에 맡긴다.
- **한 줄 고지** `.fine`: "추정 금액이에요 · 결제·송금은 하지 않아요 + 자세히". 행 전체가 토글. 펼치면 서버 원문. 다른 화면에는 페이지 끝 "안내 보기"만 둔다.
- **사람 목록** `.people`: 원형 아바타(이름 첫 글자, 장식용 `aria-hidden`) + 이름 + 한 줄 상태. 탑승 중이면 `--route-bg` 아바타, 나는 청록 링.
- **상태 표시** `.mark`: 아이콘 + 글자(확인했어요 ✓ / 기다리는 중 ◷ / 이의가 있어요 ⚠).
- **DEMO 띠**: 잉크 바탕 + 종이색 글씨, 한 줄("DEMO / 가상 데이터 · 연습용이에요"; 스크린리더에는 "실제 차량 측정값이 아니에요"가 이어서 읽힘).

## 모션

`--d-fast` 120ms(버튼 눌림), `--d-base` 200ms(아코디언 화살표), `--d-slow` 320ms(진행바, 모아 "자랐어요" 뛰기 2회), 곡선 `cubic-bezier(.2,.7,.2,1)`.
상시 모션은 모아의 6초 눈 깜빡임·바퀴 회전(홈·승인 대기·그룹 화면)과 스켈레톤 맥동뿐. `@media (prefers-reduced-motion: reduce)` 에서 전부 끈다.

## 아이콘

인라인 SVG, 24px 격자, 선 2.4px 둥근 끝, `currentColor`, 모두 `aria-hidden` — **의미는 옆의 글자가 전달**한다. 세트: check, alert, offline, lock, clock, copy, info, chevron.

## 접근성 목표 (자동 검증됨)

- 텍스트 대비 WCAG AA(4.5:1): `tokens.test.ts` 가 16개 전경/배경 쌍 + 흰 글씨 2쌍 + 비텍스트 4쌍(+입력 테두리)을 검증.
- 시각 규칙 회귀 방지(같은 파일): 2px 테두리 없음, 오프셋 그림자 없음, 그라디언트·`backdrop-filter` 없음, 노랑 토큰 사용처 정확히 1곳(`.btn--primary`), 액션 바 sticky + safe-area, `--elev` 사용 1회, 터치 48/56px, 보조 글씨 16px, reduced-motion.
- 키보드 초점: 3px 잉크 외곽선(+3px 간격) — 노란 후광은 주요 행동 전용이라 제거. "본문으로 건너뛰기" 링크.
- 상태 변화는 `aria-live="polite"`(이동 상태·정산 상태), 오류는 `role="alert"`. `lang="ko"`, 확대 허용, 폼 `label`, 진행바 `role="progressbar"`.
- Playwright + axe-core(`wcag2a, wcag2aa, wcag21a, wcag21aa`)로 참여·이동·정산·그룹·홈·404 위반 0건(증거: `docs/passenger-web.md`).
