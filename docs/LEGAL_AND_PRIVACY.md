# 법적·개인정보·운영 고지

이 문서는 법률 자문이 아니다. 아래 항목은 **출시 전에 사람이 확인해야 하는 사항**이며, 코드는 해당 기능을 켜지 않는 방식으로 위험을 줄였다.

## 구현하지 않은 것 (의도적)

결제·송금·자동 정산 이체, 공개 유상 승객 매칭·예약 수수료, 실제 기프티콘 발행/취소/교환, 차량 제어(`CONTROL_CAR_*` 권한 없음), 서버에 정밀 위치·경로를 **저장**하는 것. (외부 유가·통행료 API는 2026-11-12부터 사용한다: 아래 "외부 서비스와 위치 데이터".)

## 개인정보 (저장 · 보존 · 삭제)

| 항목 | 내용 |
|---|---|
| 저장하는 것 | 닉네임(NFKC 정규화, 제어문자 거부), 동의 버전·시각, 그룹/멤버십, 운행의 주행거리 스냅샷(km), 판독값의 출처·품질, 비용 항목, 정산·승인, 감사 이벤트 |
| 저장하지 않는 것 | 실명, 전화번호, 이메일, 차량 식별번호(VIN), 좌표/경로, 사진. GPS 궤적은 통행료 추정 요청(`POST /trips/{id}/tolls/estimate`)으로 서버가 **메모리에서만** 처리하고 저장하지 않는다(요청 본문을 로그에 남기지 않도록 리버스 프록시도 설정해야 한다) |
| 통행료 도로명 | 통행료 항목에 `서울TG→수원IC` 같은 영업소 구간 이름이 저장된다. 경로 자체는 아니지만 **대략적인 이동 구간이 드러나므로** 보존(90일)·삭제 규칙이 비용 항목과 똑같이 적용된다 |
| 토큰 | 불투명 256비트. 서버에는 SHA-256 해시만 저장. 게스트 토큰 30일, 초대 토큰 최대 24시간·20회 |
| 보존 | 기본 90일(`MOATA_RETENTION_DAYS`). `python -m app.purge` 가 오래된 운행, 그로 인해 빈 그룹, 만료 토큰, 어느 그룹에도 속하지 않은 게스트, 관련 감사 로그를 삭제 — **스케줄(cron/launchd)을 운영자가 걸어야 한다** |
| 삭제 | 그룹 소유자가 `DELETE /groups/{id}` → 그룹·운행·판독값·정산·보상·초대·(다른 그룹에 속하지 않은) 게스트 계정과 감사 로그까지 삭제. 테스트가 잔여 행 0건을 확인 |
| 접근 | 그룹 ACTIVE 멤버만 읽기. 타 그룹/없는 ID 는 동일한 404. 승인 대기자는 운전자와 본인에게만 보임 |
| 공유 카드 | 웹 정산 공유 문구는 기본으로 이름 대신 `참가자 A·B` 표기(그룹 밖 공유 권장) |
| 자유 입력 칸 | 교정 사유·메모·이의 코멘트에 사용자가 전화번호 등을 쓰면 서버는 막지 못한다(정책 안내만). 그룹 삭제/보존 작업이 함께 지운다 |

## 외부 서비스와 위치 데이터

| 서비스 | 누가 호출 | 무엇이 나가나 | 저장/캐시 | 확인할 것 |
|---|---|---|---|---|
| 오피넷 평균 유가 (한국석유공사) | 서버 (`GET /fuel-price`) | 연료·시도 코드뿐, 사용자 정보 없음 | 메모리 6시간, 하루 250건 상한(무료 키 300건) | 상업 이용은 KNOC와 협의, 화면에 출처 표시 |
| 영업소간 통행요금 (한국도로공사 오픈API) | 서버 | 영업소 코드 두 개와 차종 | DB `toll_fare_cache` (사용자 정보 없음, 30일/없음 7일) | 호출 한도 미확인, 방화벽이 User-Agent 없는 요청을 막음 |
| 자동차 표시연비 (한국에너지공단) | 개발자가 데이터를 내려받아 서버 파일로 둠 | 운행 중 외부 호출 없음 | `app/data/car_efficiency.json` | 데이터 갱신 주기 |
| 영업소 좌표 (OpenStreetMap) | 개발자가 파일로 내려받음 | 운행 중 외부 호출 없음 | `app/data/toll_gates.json` | ODbL: 출처 표시(앱·웹 화면에 문구 있음), 파생 DB 공유 조건 |
| 지도 타일 (OpenStreetMap) | **차량 앱이 직접** | 보는 지도 영역의 타일 번호와 기기 IP가 OSM 서버에 보인다 | 앱 캐시(메모리/디스크) | OSM 타일 사용 정책(식별 가능한 User-Agent, 캐싱, 대량·상용 사용 금지). 출시 때는 자체/상용 타일 서버 |
| 카카오 로컬(주차장 검색) | 서버(키 보유), **아직 화면에서 쓰지 않음** | 좌표·반경 | 저장 안 함 | 이용정책상 장소명 원본을 DB에 저장하면 안 됨(ID·URL만) |

API 키(`MOATA_OPINET_KEY`, `MOATA_EXCO_KEY`, `MOATA_DATA_GO_KEY`, `MOATA_KAKAO_REST_KEY`)는 서버 환경변수/`backend/.env`에만 두고 앱·웹에 넣지 않는다. 지도의 "지나온 길"은 차량 앱 화면에만 그려지며 서버나 승객 웹으로 보내지 않는다.

## 해결되지 않은 항목 (사람 확인 필요)

1. **카풀 비용 분담의 적법성.** 국내 여객자동차 운수사업 관련 법령상 자가용 유상운송 제한과 예외 조건이 있으므로 변호사/규제기관 확인 전에는 **유상 서비스를 켜지 않는다**. 앱은 “적법함을 보장하지 않는다”, “영리 목적 운송이 되지 않게 유의” 문구를 모든 정산 화면에 표시한다.
2. **보험·플랫폼 약관, 개인정보처리방침/동의서 문구.** 현재 `consent_version=v1` 은 자리표시자다. 실제 방침 문서와 버전 관리가 필요하다.
3. **Pleos/42dot SDK 라이선스·공식 앱 등록 심사.** SDK 라이선스(42dot)는 이미지 설치 시 사용자 동의를 받았다(`docs/emulator-provisioning.md`). 공식 앱 마켓 배포는 별도 안전·법률·개인정보 심사가 필요하며, 매니페스트의 `distractionOptimized`/`automotive` 선언은 문서로 확인하지 못했다(UNVERIFIED).
4. **쿠폰/기프티콘.** 지금은 `시연용 / 실제 교환 불가` 만 표시한다. 실제 발행은 제휴사 계약, 비용 부담 주체, 환불·만료·중복발행 방지 검증 후.
5. **릴리스 서명.** 서명 키가 없어 디버그 APK 만 있다. 키를 만들어 넣지 않았다.
6. **운영 보안.** 요청 속도 제한(리버스 프록시), HTTPS, 비밀값 관리, `MOATA_ALLOW_GUEST_AUTH=false` 와 정식 인증, `MOATA_ENABLE_DOCS=false`, 의존성 취약점 스캔(`pip-audit` 미실행).
7. **데이터 출처의 신뢰.** `PLEOS` 표시는 “운전자의 차량 앱이 보고한 값”이다(서버가 차량에서 검증하지 못함). 분쟁 가능성이 있는 상용 환경에서는 차량별 키 서명이 필요하다.
8. **미성년자.** MVP 는 만 18세 이상 지인 그룹을 전제하며 연령 확인 기능은 없다.
9. **외부 API 이용약관과 위치 동의.** 오피넷(상업 이용 협의), 한국도로공사·공공데이터포털(일일 한도), OSM 타일(대량·상용 사용 금지)의 약관을 출시 전에 다시 확인해야 한다. 앱이 위치 권한(`ACCESS_FINE_LOCATION`)을 쓰고 궤적을 서버로 보내 통행료를 계산하므로, 개인정보처리방침과 동의 문구에 이 사실을 넣어야 한다(현재 `consent_version=v1` 은 자리표시자).
10. **통행료는 추정이다.** 하이패스 실제 청구 내역을 읽는 공개 API를 찾지 못했다. 영업소 이름 매칭률은 약 66%(OSM 947곳 중 625곳에 코드가 붙음)이고, 한 번 지나면 정액인 개방식 영업소는 요금을 매기지 못한다. 화면에는 항상 "추정"을 표시한다.
